# Data Analysis — Feria del Automóvil

Análisis de datos sobre el dataset de una feria de compra/venta de autos, con visualizaciones en Power BI.

## Archivos

| Archivo | Descripción |
|---------|-------------|
| `La_Feria_Del_Automovil.xlsx` | Dataset fuente con los datos de la feria |
| `Massironi_Dataset.pbix` | Dashboard Power BI con visualizaciones y análisis |
| `EntregaFinal_DataAnalysis.pdf` | Informe final de la materia |

## Cómo abrir el dashboard

1. Instalar [Power BI Desktop](https://powerbi.microsoft.com/desktop/)
2. Abrir `Massironi_Dataset.pbix`
