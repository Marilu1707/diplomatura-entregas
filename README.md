# Diplomatura — Entregas por Materia

Repositorio con los trabajos prácticos de la diplomatura, organizados por materia. Solo se incluyen materias con componente práctico (se excluyen Cultura Digital, Metodologías Ágiles y similares).

## Estructura

```
diplomatura-entregas/
├── bases-de-datos/     # Bases de Datos — esquema MySQL estrella
│   ├── sql/            # Scripts: schema, datos, vistas/funciones/triggers
│   ├── docs/           # Informe final + DER
│   └── data/           # Dataset fuente
├── data-analysis/      # Data Analysis — análisis con Power BI
│   ├── La_Feria_Del_Automovil.xlsx
│   ├── Massironi_Dataset.pbix
│   └── EntregaFinal_DataAnalysis.pdf
├── excel/              # Excel — proyecto final
│   └── ProyectoFinal_Massironi.xlsx
└── power-bi/           # Power BI — entrega final
    └── Massironi_Dataset.pbix
```
